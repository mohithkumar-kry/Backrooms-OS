# 🖥️ Backrooms OS (Dream_oS)

> A nostalgic, retro Windows 95/98-style fake desktop OS — built for fun in the browser. 🌫️🪟

Made by a first-year ECE student who just wanted to relive the good old blue-and-gray desktop days. 😄

---

## ✨ Features

- 🪟 **Draggable retro windows** — click and drag any window by its title bar, just like the good ol' days
- 🖱️ **Start-style dropdown menu** — click "Dream_oS" in the top bar to launch apps
- 🕐 **Live clock** — always know what time it (isn't) in the Backrooms
- ❌ **Closable windows** — click the ✕ to banish a window back into the void
- 🎨 **Authentic beveled UI** — that classic 3D gray Windows look, made with pure CSS box-shadows

## 🧰 Built-in Apps

| App | Icon | What it does |
|-----|------|---------------|
| Dream OS Welcome Window | 🖥️ | The default "Welcome to Dream OS" popup |
| Calculator | 🧮 | Basic arithmetic, just like the real Windows calc |
| Notepad | 📝 | Type your Backrooms survival notes |
| YouTube | ▶️ | Watch videos without leaving the desktop |
| About | ℹ️ | Learn more about Dream_oS |
| Shut Down | ⏻ | ... it's now safe to close this tab |

## 🛠️ Tech Stack

- 🧱 HTML
- 🎨 CSS (pure, no frameworks — hand-crafted retro bevels!)
- ⚡ Vanilla JavaScript (no libraries, just good old DOM manipulation)

## 🚀 Getting Started

1. 📥 Clone this repo
   ```bash
   git clone https://github.com/yourusername/backrooms-os.git
   ```
2. 📂 Open `index.html` in your browser
3. 🖱️ Click around, drag windows, open apps, and enjoy the nostalgia!
